# Prosopopus Studio - Vision & Philosophy

Prosopopus is an autonomous vector interpolation engine and interactive generative shape studio.

## Core Pillars

1. **Continuous Multi-Axis Interpolation**:
   - Seamless shape metamorphosis driven by continuous parametric axes (X, Y, and custom axes).
   - Inverse Distance Weighting (IDW) and Bilinear Grid interpolation strategies.

2. **Dual-Mode Workflow**:
   - **Standard Matrix Mode**: Clean, immediate 2D spatial positioning for direct mouse/physics-driven exploration.
   - **Expert Mode (Timeline & State Machine)**: Non-destructive enhancement adding temporal keyframe sequencing, loops/ping-pong playback, easing curves, and element-level interaction triggers (click, hover enter, hover leave, animation end).

3. **Universal Embed & Zero-Dependency Runtime**:
   - Works identically in Studio Play Mode and standalone web embeds (`prosopopus-player.js`).
   - High performance 60fps rendering via HTML5 Canvas with sub-pixel interpolation, vertex inertia, and spring physics.
